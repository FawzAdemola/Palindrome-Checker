Palindrome Checker

A practice web app that checks whether a string or number is a palindrome (reads the same forwards and backwards).

## Features
- Input string or number and immediately see result (palindrome or not)  
- Clear UI feedback for user input (valid / invalid)  
- Responsive layout styled with CSS for different screen sizes

## Technologies
- HTML5  
- CSS3  
- JavaScript (ES6) for logic and DOM / event handling  
- Git & GitHub for version control
